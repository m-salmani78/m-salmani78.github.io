# m-salmani78.github.io

Personal academic CV site hosted on GitHub Pages at [https://m-salmani78.github.io](https://m-salmani78.github.io).

## Editing

1. Update [My_CV.md](My_CV.md) with your latest CV content.
2. Sync the same changes into [index.html](index.html).
3. Commit and push to the `main` branch.

## Local preview

Open `index.html` in a browser, or use a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

GitHub Pages is configured to deploy from the `main` branch, root folder (`/`). After pushing, the site updates within a minute or two.
